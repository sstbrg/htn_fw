UART protocol

Frame format, every opcode, reply layouts, status bits and the bootloader commands.

Frame format

The host link is 921600 baud, 8 data bits, no parity, 1 stop bit, no flow control, received with DMA to idle. A frame is received whole: the application takes it when the line goes idle, then checks that the length byte equals the number of bytes received and that the checksum matches. A frame that fails either check is ignored silently (no reply), so the host must time out and resend.

An unknown opcode is answered with 0xEE and the offending opcode as payload. A reply carries the opcode of the request.

STATUS reply (opcode 11)

Fields in order: SW (9 bytes, NUL-terminated version), HW (u8), self_id (u16), LoRa last RSSI and SNR (i8), errors, battery (state of charge, 0 when there is no gauge), LoRa receive counter (u32), LoRa frequency (u32), UWB tag status, UWB backoff in ms left (u32), last UWB status register (u32), UWB TX and RX counters and is_tag. The anchor adds the fault counters. With LINK_F_REPLY_EXT set the anchor appends the link-state block: active feature mask, link flags, requested profile, tag profile echo, requested and echoed LoRa power, UWB levels, LDE preset, K used, current profile and last revert reason. Without that bit the reply ends before the block, exactly as in anc3.1.5.

Bootloader opcodes

The bootloader answers the same frame format on the same port:

OpcodeNameBehaviour
10RESETClear the update flag, reply, reset after 1 s.
11STATUSVersion (sC3.0.65), hardware revision (HW = 255 identifies the bootloader to the tools), battery.
16START_PROGMass-erase bank 2. Reply may take several seconds.
17WRITE_BUFFER128 bytes, written at the running address, which starts at 0x08200000 and grows by 128 per frame; refused outside 0x08200000 to 0x08400000 or before START_PROG.
18HEADER_FILECRC (u32) and length (u32). Stores the header, recomputes the CRC over 255 pages and jumps to the application on a match; error reply otherwise.
0xEEERRORReply to an invalid request.

The loader resets itself after 60 s without a valid frame.
