Anchor project (Anchor/)

Anchor firmware, version anc4.0.0. Files under Core/ are the application; the DW1000 driver, the SX126x library and the CubeMX peripheral code are vendor or generated code that HITAN edits only inside USER CODE markers.

Anchor/Core/Src/

FileContents
BMI088.cBMI088 driver on SPI1: initialisation and chip-id check, register read and write, polled and DMA sample reads, BMI088_ReadRaw for the host opcode. Sets the no_IMU flag when the chip does not answer.
Led.cppAnchor LED maps for rev C1 and C2: four battery-bar LEDs, BIT fail, BIT pass and link-up; battery bar from the gauge; FOTA status and link LED hooks; LED test.
adc.cCubeMX ADC4 initialisation and pin setup.
burn_mode.cLegacy UART programming-mode loop; the whole body is commented out, kept for reference.
crc.cCRC peripheral setup (STM32 CRC-32 over bytes) and CRC_File_Handler, which creates or checks the application header page in bank 2 at start-up.
dw1000.cppAnchor UWB layer: DW1000 init, configuration and recovery; scan mode with backoff arming; range exchange and round (K repeats, shortest kept); CIR window and diagnostics latching; imposter (stand-in tag) mode; link negotiation, UWB power levels, LDE preset, extended poll v1/v2, configuration-item queue, range-profile control.
flash.cCubeMX flash peripheral initialisation.
flash_handler.cppFlash write and erase with ICACHE invalidation, the jump into the bootloader, and the optional reset counter kept in the self-id page.
fota.cFOTA loader and target state machines: UART commands, image buffer in RAM, UWB handshake, chunked transfer with acknowledgements, rate fallback, CRC check, flash write with read-back and retries, discovery list. Identical in Anchor and Tag.
fota_port.cppBoard-specific hooks for FOTA: self address, kind, hardware revision, battery, LEDs, restoring the normal UWB configuration, UART send, watchdog kick.
gpdma.cCubeMX GPDMA channel setup for the UART and SPI transfers.
gpio.cCubeMX pin configuration for every board signal (radios, LEDs, hardware-revision pins, anchor id pins, IMU, UART power enables).
i2c.cCubeMX I2C2 initialisation (battery gauge bus).
icache.cCubeMX instruction cache enable.
main.cppAnchor entry point and main loop: clocks, MPU, peripherals, self id and hardware revision, DW1000 and LoRa start, the host opcode switch (SEARCH_TWR, SET_ID, STATUS, raw register access, link features, tag configuration, profiles, IMU, FOTA, update request), LoRa wake-up sequencing. Also the command helpers for antenna delay, crystal trim, CIR, IMU, link features, tag config and profile.
memorymap.cCubeMX memory-map init stub.
rrc2040driver.cRRC2040 SMBus battery driver on I2C2: voltage, current, temperature, remaining capacity and state of charge. Reports a no-gauge value when nothing answers.
rtc.cRTC setup and the TAMP backup registers: fault counters (NMI, HardFault, MemManage, BusFault, UsageFault, watchdog) and the update-request flag.
spi.cCubeMX SPI1 (IMU), SPI2 (LoRa) and SPI3 (DW1000) setup.
stm32u5xx_hal_msp.cHAL MSP init: low-level clocks and pins shared by peripherals.
stm32u5xx_it.cInterrupt handlers: fault handlers that bump backup-register counters, EXTI4 (radio DIO1), GPDMA channels, TIM4 (1 ms tick, software watchdog), USART3 and USART6. Contains refresh_WD().
syscalls.cNewlib system-call stubs generated by STM32CubeIDE.
sysmem.cNewlib heap (_sbrk) generated by STM32CubeIDE.
system_stm32u5xx.cCMSIS system init: clock variables and vector-table setup.
tim.cCubeMX TIM2 and TIM4 setup. TIM4 gives the 1 ms tick.
uart_communication.cAnchor reply builders (TWR, status, diagnostics, wake-up, BIT, raw access, backoff, reset counter, errors), checksum and validation; replies that grew in 3.2.0 are cut to their legacy length unless REPLY_EXT is on.
usart.cUSART3 and USART6 setup (921600 8N1), DMA receive-to-idle, UART error callback that re-arms the receiver, UART_GetMessage and UART_SendMessage. The port in use depends on the hardware revision.
