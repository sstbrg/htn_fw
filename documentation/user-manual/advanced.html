Bench, diagnostics & setup

ADVANCED workspace

Switch to ADVANCED for device connection, live single-anchor ranging, RF diagnostics, multi-anchor setup, calibration and radio configuration.

Connect to a device

The connection bar offers a serial Port selector, Refresh ports, Connect/Disconnect, a Backoff checkbox and palette toggle. Default baud is 921600. One device may be connected for single-anchor work; the Configuration tab separately opens up to four assigned anchor ports. A port can be owned by only one active workflow at a time.

Live Device

  • Set Tag / Anchor ID to the target ID.
  • LoRa only limits operation to LoRa measurement.
  • Diag+CIR every frame captures full diagnostic and channel impulse response each frame. This is slower; leave off for faster ranging.
  • Record .hpb saves the run. Optional Mobile anchor metadata and free-text notes are included in the finalized filename; notes can be edited during the run.
  • Press Start to run and Stop to finalize. The panel reports samples, average round-trip time, rate and loss and plots recent distances. Diag+CIR mode also fills a live CIR waterfall.
  • Snapshot + CIR takes one diagnostic/CIR sample from a connected idle device and opens it in Snapshots. It is unavailable while the device is occupied by live ranging.

Use Open TWR recording… to load a TWR .hpb or legacy CLI .txt loop log. Trilateration .hpb files belong in the Configuration tab's playback panel.

TWR Performance

Uses the loaded TWR recording when present; otherwise falls back to the live TWR ring. It reports valid range count, mean, standard deviation and loss, then plots distance and (when available) LoRa RSSI histograms.

Configuration

Station setup and ranging, for both station builds (the tab is not called Trilateration because a MOB station, with one UWB antenna, cannot trilaterate). Assign distinct serial ports to front (main), right (main), and left (main); optionally assign a fourth as spare. Enter tag ID, choose whether to record, and select Mobile (upright) or Regular (upside down — L/R mirrored). Press Start ranging. In FLY the three mains range the tag in turn over UWB; in MOB only the front anchor ranges over UWB and the right and left anchors report LoRa. The spare stays connected but idle and may replace a main after repeated failure. Stop to release ports and finalize the recording.

The live card reports round number/time, active anchors and spare state. Pipeline controls include UWB slew and outlier gating, estimator selection (raw, polar Kalman or smoother), the smoother's window, lag and robust loss, LoRa direction gates/smoothing, the adaptive distance/speed rules, the standing-still model (mode memory and still drift) and the quality checks. Hover a control for its built-in explanation. These settings can affect the running solve and playback; use defaults unless you understand the measurement tradeoffs.

Quality checks: check each UWB reading reads the anchor's receive diagnostics after every valid exchange. A reading whose total power exceeds its first-path power by more than reflection from dB is trusted less, and only above drop at dB (20 by default; a reflective room sits at 8–11 dB all day) is it dropped. A first path more than direct drop dB weaker than that anchor has lately been giving is dropped as a weak first path; this test is relative to the anchor's own recent readings, so it follows the radio settings and the room by itself. cross-check anchors drops a range that cannot be consistent with another anchor's given their spacing, with an allowance for the station's own motion between the sequential exchanges.

For replay, choose Open trilat .hpb…, then Play recording. Replay uses the same processing/compass path as live data and appears on LOCATE.

Anchor Station geometry

The geometry table holds up to four anchors. Enter IDs (hex such as 0x2 or decimal) and roles. The first/front anchor is fixed at (0,0,0); set other positions in metres relative to it: right is +X, forward is +Y, up is +Z. Empty ID means unused. Save requires at least three distinct IDs; preview shows layout and pairwise distances.

Geometry is stored in trilat_geometry.json in the application working directory and embedded in trilateration recordings. Correct coordinates and roles are prerequisites for a meaningful solve.

LoRa Cal

This tab maintains per-anchor LoRa RSSI offsets and patch boresights. Capture baseline (from live RSSI) establishes a reference from current signal levels; Clear calibration removes calibration. Data is stored in trilat_lora_cal.json. An uncalibrated station warns that direction is unreliable. Calibrate with tag and station in known positions; environmental changes can invalidate a baseline. The LoRa arc is direction only; no distance is derived from LoRa signal level.

Radio Registers

Radio Registers edits a device radio profile. Select operating context (channel, PRF, rate, PAC, preamble and related settings), then Build recommended or Load JSON…. Review the hex write list, validation errors/warnings and notes. Use Save JSON… to save a profile.

Applying writes changes radio registers on the connected device. Confirm the target and required radio settings first. dry run records what would be written without UART writes. With dry run off, Apply over UART sends register values. Use Verify to read back supported values. If disconnect interrupts an apply, reconnect and choose Resume apply; inspect failed, skipped, uncertain and pending entries.

Only a connected single device can be configured through this panel. Validation errors disable apply.
