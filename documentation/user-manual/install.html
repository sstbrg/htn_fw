Getting started

Install & launch

Choose the Debian package for a field tablet, the offline installer for a tablet with no network, or build the desktop binaries from source.

Option A · Debian package

Install the provided hitan-analyzer_…_amd64.deb on a compatible Ubuntu amd64 desktop:

sudo apt install ./hitan-analyzer_*.deb

The package installs the analyzer and the hitanpy CLI, adds the launcher, installs USB serial/backlight udev rules, creates /var/lib/hitan, and adds the installing account to dialout and video. A network connection may be needed if runtime libraries are missing.

After installing: log out of the desktop session and log back in once. This activates serial-port (dialout) and backlight (video) access. Rebooting also works.

Launch HITAN Analyzer from the desktop menu, or run:

hitan-analyzer

The package launcher starts the application with /var/lib/hitan as its working folder so recordings and station settings are stored there.

Option B · Offline installer (no network)

Each release also carries hitan-analyzer-offline_…_amd64.run: one file holding the Debian package and its entire dependency tree, down to the C library, built for Ubuntu 24.04. It needs no network at any point.

  1. Copy the .run file to a USB drive.
  2. Plug the drive into the Ubuntu 24.04 tablet and open a terminal.
  3. Run it using the mounted drive path, for example:
    bash /media/$USER/Data/hitan-analyzer-offline_*.run
    The file does not need its executable bit. It asks for your password to install.
  4. For automatic launch at desktop login, append --autostart to the command.
  5. Log out and back in after installation.

The installer first verifies its own checksum (a damaged copy is refused before anything changes), then checks the machine is amd64 Ubuntu 24.04 with a compatible glibc. It installs only what the tablet is missing: a full desktop receives just the analyzer; a minimal system also receives the graphics libraries. The tablet's own package sources are not used or changed. Re-running it is safe; an older installer rolls the analyzer back. --check verifies the file without installing. Remove with sudo apt remove hitan-analyzer — recordings in /var/lib/hitan are kept.

Option C · Build from source

Install Rust and the system libraries needed by the eframe desktop application, then build from the repository root:

cargo build --release
./target/release/hitan-analyzer

# Optional command-line utility
./target/release/hitanpy

The repository is a Cargo workspace. The analyzer is in crates/hitan-analyzer; shared device/protocol code is in crates/hitan-core. No system protoc or libudev-dev is required by this project build. A Rust toolchain compatible with the workspace manifest is required.

Older tablets: Linux binaries depend on the glibc version on the target. A build made on a newer distribution may not run on an older tablet. Use a compatible build environment or prepared package/deployment artifact.

Connect hardware

  • Connect USB serial adapters for anchors. In Advanced, the port picker lists ports; use Refresh ports after connecting.
  • LOCATE probes USB serial ports while idle and identifies anchors that reply to the HITAN status request.
  • The configured baud rate is 921600.
  • The udev rule sets FTDI latency to 1 ms for faster exchanges, grants serial access to dialout, and allows video to control display backlight where supported.
  • Connect the tag and ensure it is powered and configured for the station's radio settings.

First-run checklist

  1. Confirm the application opens in the desktop session.
  2. Confirm your account has dialout access after logging back in.
  3. Connect anchors, wait for presence/status to update, and verify anchor IDs against your station plan.
  4. Confirm station geometry and roles match the physical layout before relying on trilateration.
