HITAN Analyzer

HITAN Analyzer is a native Linux desktop tool for operating HITAN UWB/LoRa tags and anchors. Use the touch-friendly LOCATE screen in the field, or switch to ADVANCED for live ranging, RF diagnostics, station setup, configuration and recording playback.

🐈 LOCATE

Enter a tag ID, scan connected anchors, and read the direction and range on the operator dial. Includes mobile/fixed station modes, signal confidence, health status and recording playback.

What you need

  • A Linux desktop or field tablet with a graphical session. The supplied Debian package targets amd64 Ubuntu.
  • HITAN-compatible STM32 UWB/LoRa tag(s) and USB serial anchor adapters for radio operations.
  • For trilateration, a configured station with three main anchors and optionally a fourth spare. Correct station geometry is essential to meaningful direction and distance.
Two views: LOCATE is the focused operator workflow and manages anchor ports when you press SCAN. ADVANCED exposes individual tools. Switch views with the buttons in the top bar.

Quick start

  1. Install the Debian package or build from source using the installation guide.
  2. Connect the hardware to USB. Log out and back in after installation so new dialout and video group permissions take effect.
  3. Open HITAN Analyzer. In LOCATE, tap the search icon, enter the tag ID, then press SCAN.
  4. When anchor status appears, go to the dial. Select the correct MOB or FLY station mode and use the displayed bearing/range according to your configured setup.
  5. In ADVANCED, use Live Device for single-anchor TWR and Snapshots & Analysis to open a recording.

Other program in the package

The optional hitanpy command-line utility is a separate numbered-menu tool for direct device commands, such as status, raw register access and firmware operations. This manual focuses on graphical hitan-analyzer. Launch the CLI in a terminal with hitanpy; its command prompts describe requested values.
