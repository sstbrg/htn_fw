When the signal goes quiet

Check ports, permissions, tag IDs, station geometry and recording type before diagnosing radio behavior.

Common issues

SymptomWhat to check
No ports / anchors foundReconnect USB adapters; press Refresh ports in Advanced or wait for LOCATE probing. Check account dialout access and log out/in after installation. Ensure adapter is a supported USB serial device.
Port busy / connect fails during scanStop the LOCATE scan, or ranging on the Configuration tab, first. A running worker owns its serial ports.
Scan runs but no useful fixVerify tag ID, tag power/radio configuration, anchor IDs and roles, mounting selection, geometry and antenna visibility. Check packet loss and main-anchor activity.
Header stays on WAKING TAGNo anchor hears the tag on UWB or LoRa, so the wake-up keeps going out every two seconds. A sleeping tag listens on LoRa about half the time and needs a packet to land; a tag waking from deep sleep restarts and listens for six seconds. Check the tag ID, that the tag has battery, and that the sending anchors have working LoRa (the Configuration tab names the anchor of the last wake-up and whether it accepted the request). A tag out of LoRa range cannot be woken from the station.
Direction appears mirroredSelect correct MOB (upright) or FLY (upside down) orientation. Confirm anchor roles and station layout in Anchor Station.
LoRa arc is absent/unreliableCheck LoRa packets and saved station baseline/calibration. Per-anchor RSSI offsets and geometry/boresights affect direction.
Plots are blankUse the right loader: TWR logs in Snapshots; trilateration recordings in the Configuration tab's playback card. An all-lost TWR recording has no distance points.
No CIR/diagnostic plotsThe recording needs diagnostic rows. Enable Diag+CIR every frame before recording or take Snapshot + CIR. A TWR-only recording cannot reconstruct CIR later.
App will not launchCheck Ubuntu GUI runtime libraries and binary glibc compatibility. A binary built on a newer distribution may require newer glibc than the tablet provides.
Backlight slider only dims appSoftware dimming is used when host backlight writes are unavailable. The installed udev rule and video group access enable hardware brightness where supported.

Files and storage

Paths are relative to the application's working directory. A package installation uses /var/lib/hitan; a source launch uses the current directory unless launched elsewhere.

File/folderPurpose
recordings/<date>/Generated TWR snapshots/live logs and trilateration recordings.
trilat_geometry.jsonSaved anchor IDs, roles and station coordinates.
trilat_lora_cal.jsonSaved LoRa calibration.
hitan_station.cfgOptional startup mounting mode: mode = mob or mode = fly; defaults to MOB if missing.
.hpbLength-delimited protobuf recording format shared with Python HITAN tools. May contain TWR samples or trilateration rounds; use the corresponding loader.
.txtLegacy CLI TWR loop log, readable from Snapshots & Analysis.

Capture quality checklist

  • Use expected tag and anchor firmware/radio profile.
  • Confirm station geometry is measured in metres and roles match physical mounting.
  • For diagnostics, enable Diag+CIR capture or take a snapshot; it reduces ranging speed.
  • Record operator notes and whether the anchor is mobile when relevant.
  • Stop a run normally so partial recordings are finalized and named.
  • Preserve original recordings before recalibration or reconfiguration.
